# Code of Conduct

## Our Standard

Participants in this project are expected to be respectful, technically honest, and constructive. Welcome questions, document assumptions, and focus criticism on designs and code rather than people.

Unacceptable behavior includes harassment, discrimination, personal attacks, intentional disruption, and publishing private information without consent.

## Enforcement

Report conduct concerns privately to the repository maintainers through the contact method configured in the repository settings. Reports will be reviewed fairly and kept confidential where possible. Maintainers may remove comments, close discussions, or restrict participation when necessary to protect the project community.
