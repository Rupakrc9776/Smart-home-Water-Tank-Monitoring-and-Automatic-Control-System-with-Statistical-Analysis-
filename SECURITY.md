# Security Policy

## Supported Version

The current `main` branch is the supported development line.

## Reporting a Vulnerability

Do not open a public issue for credentials, private serial data, electrical safety defects, or exploitable software behavior. Use GitHub's private security advisory flow or contact the repository maintainers through a private channel configured in the repository settings.

Include:

- affected file and version or commit;
- reproducible steps and expected impact;
- hardware configuration, if applicable;
- a minimal mitigation or patch when available.

Never include tokens, passwords, personal data, or mains wiring photographs containing private information. Physical electrical hazards should be de-energized immediately and reviewed by a qualified person.
