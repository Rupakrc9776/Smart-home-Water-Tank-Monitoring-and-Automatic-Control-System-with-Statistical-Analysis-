# Python Dashboard

The runnable Python entry points remain at the repository root for compatibility:

- `dashboard.py`: Tk/ttkbootstrap live dashboard.
- `water_logger.py`: headless append-only serial logger.
- `dashboard_assets.py`: canvas drawing helpers and color definitions.

Run from the repository root after installing `requirements.txt`:

```powershell
python dashboard.py
```

See [../Documentation/Dashboard.md](../Documentation/Dashboard.md) and [../Documentation/Software.md](../Documentation/Software.md).
